# ربط لوما بمشروع Supabase — خطوة واحدة

الكود جاهز بالكامل. الموقع يعمل اليوم على تخزين المتصفح، وبملء ملف
إعداد واحد يتحوّل إلى السحابة بلا أي تغيير في الشاشات.

## 1) إنشاء المشروع
من لوحة Supabase: مشروع جديد في منظمتك — **المنطقة: أوروبا الوسطى
(eu-central-1)** أقرب زمن استجابة للسعودية. الخطة المجانية تكفي للبداية.

## 2) تشغيل الهجرات بالترتيب
من `SQL Editor` أو عبر الـ CLI، بهذا الترتيب بالضبط:

```
luma-hr/supabase/migrations/0001_hr_schema.sql     الجداول والأنواع وسياسات RLS
luma-hr/supabase/migrations/0002_hr_logic.sql      محرك التوفر وحارس الحجز
luma-hr/supabase/migrations/0003_hr_upgrade.sql    الأرصدة والحضور والرواتب
luma-hr/supabase/migrations/0004_public_pages.sql  الصفحات العامة والروابط
```

النتيجة: 14 جدولاً كلها بـ RLS، وقيدا منع تداخل، وثمانية مشغّلات.

## 3) توقيت الصالون
حدود الدوام والاستراحات تُقارَن بتوقيت الصالون لا بـ UTC. الافتراضي
`Asia/Riyadh`، ويُضبط لكل جلسة عبر:

```sql
select set_config('app.salon_tz', 'Asia/Riyadh', false);
```

## 4) ملء الإعداد
في `luma-config.js` بجذر المشروع:

```js
window.LUMA_CONFIG = {
  supabaseUrl: 'https://<project-ref>.supabase.co',
  supabaseAnonKey: '<المفتاح العام من Project Settings ← API>',
  salonTz: 'Asia/Riyadh',
};
```

⚠ المفتاح العام (anon) فقط — مصمَّم للنشر في المتصفح، وحمايته الحقيقية
سياسات RLS. **مفتاح `service_role` لا يوضع في متصفح أبداً.**

## 5) ترحيل بيانات المالكة
من وحدة تحكم المتصفح داخل `salon.html`:

```js
await LumaMigrate.preview()   // ماذا سيُرحَّل — بلا أي كتابة
await LumaMigrate.run()       // التنفيذ، ويعيد تقريراً مفصّلاً
```

لا يُحذف من المتصفح شيء، ولا يُرحَّل شيء مرتين. الحجوزات التي يرفضها
حارس الخادم (خارج الدوام أو متعارضة) تظهر في التقرير بسببها.

## التحقق قبل النشر
```bash
bash luma-hr/supabase/tests/run.sh     # 12 اختباراً للمخطط على PostgreSQL محلي
npx playwright test tests/phase-b.spec.js
```

## ما يبقى بعد هذه الخطوة
المخطط يغطّي الطاقم والحجوزات والرواتب والصفحات العامة. أمّا العميلات
والفواتير والمخزون والولاء والكوبونات والتقييمات وتحليلات الزيارات فلا
جداول لها بعد — تلك المرحلة ج في `ROADMAP.md`.
